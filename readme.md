# 🎱 Streamlit 로또 번호 생성기

Streamlit을 활용하여 만든 간단하고 직관적인 로또 번호 생성기 애플리케이션입니다.

## 📌 주요 기능
- **랜덤 번호 생성**: 1부터 45까지의 숫자 중 중복 없는 6개 번호를 무작위로 추출하여 자동 정렬합니다.
- **실제 로또 공 색상 반영**: 번호 구간별로 실제 로또 공과 동일한 색상(노랑, 파랑, 빨강, 회색, 녹색)의 동그란 공 디자인으로 표시됩니다.
- **최대 5개 세트 누적**: [로또번호 생성] 버튼을 누를 때마다 최근 생성된 번호가 상단에 추가되며, 최대 5개 세트까지 기록을 유지합니다.
- **초기화 기능**: 생성된 번호 내역을 한 번에 비울 수 있습니다.

## 🎨 로또 공 색상 기준
- **1 ~ 10**: 노란색
- **11 ~ 20**: 파란색
- **21 ~ 30**: 빨간색
- **31 ~ 40**: 회색
- **41 ~ 45**: 녹색

## 🚀 실행 방법

### 1. 필수 라이브러리 설치
```bash
pip install -r requirements.txt
```

### 2. Streamlit 앱 실행
```bash
streamlit run app.py
```
*(파일명이 `app.py`가 아닌 경우 해당 파일명으로 변경하여 실행해 주세요.)*
