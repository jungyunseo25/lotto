# 🎱 Streamlit 로또 번호 생성기

Streamlit을 활용하여 만든 직관적이고 깔끔한 로또 번호 생성기 애플리케이션입니다.

## ✨ 주요 기능
- **랜덤 번호 생성:** 1부터 45까지의 숫자 중 중복 없는 6개의 번호를 무작위로 추출하여 자동으로 오름차순 정렬합니다.
- **실제 로또 공 색상 반영:** 번호 구간별로 실제 로또 공과 동일한 색상(노란색, 파란색, 빨간색, 회색, 녹색)의 동그란 공 디자인으로 표시됩니다.
- **최대 5개 세트 누적:** [로또번호 생성] 버튼을 누를 때마다 최근 생성된 번호가 상단에 추가되며, 최대 5개 세트까지 기록을 유지합니다.
- **초기화 기능:** 기록된 전체 번호 세트를 비울 수 있는 초기화 버튼을 제공합니다.

## 🛠️ 기술 스택
- **Python**
- **Streamlit**

## 🚀 실행 방법

1. 필요한 라이브러리를 설치합니다:
   ```bash
   pip install -r requirements.txt
   ```

2. 애플리케이션을 실행합니다:
   ```bash
   streamlit run lotto.py
   ```
